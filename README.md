# 🚗 Car Price Prediction System

A Machine Learning based web application that predicts the price of used cars based on various features.

## 🌐 Live Demo

🔗 https://car-price-prediction-1-y3x3.onrender.com/

## 📌 Features

- Predict Used Car Price
- Real-Time Car Image using Pexels API
- Responsive User Interface
- Machine Learning Prediction
- Live Deployed on Render

## 🛠️ Tech Stack

- Python
- Flask
- Pandas
- NumPy
- Scikit-learn
- HTML
- CSS
- JavaScript
- Bootstrap
- Pexels API
- Render

## 🚀 Installation

```bash
git clone https://github.com/ansh1268/car_price_prediction.git
cd car_price_prediction
pip install -r requirements.txt
python app.py
```

Open:

```
http://127.0.0.1:5000
```
